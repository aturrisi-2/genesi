Benvenuto nella cartella dei manuali di Genesi.

Qualsiasi file di testo (.txt) o file JSON (.json) caricato in questa cartella verrà analizzato ed indicizzato automaticamente da Genesi.
Quando l'utente fa una domanda, Genesi cercherà le parole chiave più rilevanti all'interno di questi manuali ed inietterà autonomamente le sezioni corrispondenti nel suo contesto per formulare la risposta.

Formati supportati:
1. File TXT (.txt): il testo viene suddiviso in paragrafi separati da doppie andate a capo (\n\n).
2. File JSON (.json): può contenere una lista di stringhe o un dizionario con una lista di blocchi aventi campi "text" e "title".
